## 已知结果和问题

- V6 在选定无画师近景中减轻 V4/V5 的发白，六张发色对照保留紫色发顶；暗场亮度、服装附加、视线服从仍不完全稳定。
- 全身小脸的瞳孔、眼形仍可能出错。分辨率和局部修复能改善部分样本，未证明仅靠多训一轮可以解决。
- 数据覆盖偏近景；明确全身 16 张且集中于两类服装。下一轮应先改善覆盖，再用相同对照比较。
- 新版评估续跑校验有效 API 图和已保存图片摘要，拒绝只按名称复用。旧结果没有摘要时保留原件，另建评估目录。

详细证据与限制：[RESULTS](RESULTS.md)。人设标准：[DATASET](DATASET.md)。

## 推荐下一步

1. 新机器先完成 [迁移检查](MIGRATION.md)；无 GPU 的云端只做 [辅助开发验证](CLOUD.md)。
2. 需要继续模型研究时，先复核全身图的小脸、服装和角度覆盖，保留现有数据和模型。
3. 用户要求开展训练后，先做明确配置的短训练验证显存，再决定完整训练；不自动接续旧 LoRA。
4. 曝光、人设和全身眼部都纳入验收；同场景固定种子，曝光对照去掉画师词。
