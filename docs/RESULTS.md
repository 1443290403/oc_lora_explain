# 已观察到的结果与局限

这里只保留参数和结论，不发布实验图片、逐图源数据、文件路径、聊天记录或模型权重。

## V6 重新训练

V6 从原始 waiIllustriousSDXL_v170 底模新建，未接续 V4/V5。使用用户复核过的100张图片；896分桶、rank/alpha16/16、UNet注意力层、学习率5e-5、8轮×2重复、batch1，共1600步。禁用水平翻转和色彩增强，未训练文本编码器。

本次完整训练约32.5分钟，整卡显存峰值7703MiB，最终LoRA约44.54MiB、1680个有限张量；没有OOM。这是具体机器上的实测，不是通用性能保证。

## 曝光与人设：32张验证

- 12张比较三个场景中的底模、V4、V5、V6；6张检查V6三个种子、0.7/1.0强度；6张检查400/800/1200步中间点。
- 根据暗场残留问题补充8张：中间点暗场、强度变化、独立RescaleCFG实验及表情服装变化。共32张均无画师词，其中29张无RescaleCFG，3张只为比较该节点。
- 披萨日常和灰背景中，V6比V4/V5减轻了大面积发白，恢复更多明暗层次。披萨全图近白比例约从23.7%/24.3%降到3.6%；它包含衣服和背景，不能当作皮肤过曝面积。
- 暗剧场强度1.0仍容易生成明亮金色灯饰；0.7在该种子更接近深暗聚光灯氛围。单加RescaleCFG0.5/0.7没有解决全部偏向。
- 六张近景测试均保留紫色发顶与薄荷绿渐变，没有复现旧版种子456在0.7下全绿的情况。它不能证明全部随机种子、人脸角度和遮挡都稳定。
- 闭眼笑、惊讶和红色卫衣可变化；阴天仍会偏亮，黑色高领外可能附加浅色外套，侧视未完全服从。仅触发词常带出黑白衬衫或女仆式衣物。

较早检查点有全绿发色、方向和发饰错误。最终1600步在所选近景灰背景中更好，因此本次主版本没有回退；也未自动追加另一轮完整训练。

offset noise0.03是一次本地SDXL实验，训练同时改变了数据、标签和配置，因此无法把改善单独归因于该参数，也没有证明唯一曝光根因。[原始offset noise说明](https://www.crosslabs.org/blog/diffusion-with-offset-noise)的实验基于SD1.x，应与本轮结果区分。

## 全身眼部：额外20个测试

用 `naikaer_oc, 1girl, solo, black dress, standing, full body,` 做18张生成对照，再做两张人工定位脸部的局部重绘，全程没有画师词或RescaleCFG。

结论是V6的全身小脸确实比近景不稳定，降低权重并非眼部修复开关。直接1024×1536和图像放大重绘改善清晰度，但种子456的瞳孔仍可能不规整。把脸部单独放大重绘，在两例中让绿色虹膜和瞳孔更规整，最终仍要人工检查。

明确全身样本仅16张且服装集中，近景占比高，是下一轮数据复核应处理的风险。不能仅增加训练轮数就承诺修好眼睛；也不能把本次有限测试概括为“V6所有全身图都模糊”或“问题全部来自分辨率”。

后续应增加正确、清晰的全身站姿小脸，平衡距离、服装和角度，并把全身眼部放大检查纳入验收，而非只看曝光、发色或缩略图。
